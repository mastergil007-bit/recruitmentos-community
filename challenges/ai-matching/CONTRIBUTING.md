# Contributing to the AI Matching Challenge

You can contribute complete matching engines, alternative scoring methods, prompt architectures, semantic approaches, rules engines, test cases, evaluation methods, explainability approaches, bias and fairness testing, documentation, or architecture proposals. A small, well-explained improvement is welcome.

Place a solution under `challenges/ai-matching/solutions/<github-username-or-project-name>/`. Its README should include:

1. Approach and reasoning.
2. Technologies.
3. How to run on the synthetic examples.
4. Expected output and a sample result.
5. Known limitations.
6. External APIs/services and the synthetic data shared with them.
7. Privacy and security considerations.

Follow the [rules](RULES.md), use the [data](data/jobs.json) and [candidate set](data/candidates.json), and compare behavior against the [reference cases](data/reference-cases.json). Open an issue for a question or a test-case proposal; submit a pull request for a documented contribution. Do not include real CVs, personal data, credentials or private Recruitment OS implementation.

We care less about matching words. We care more about understanding job-relevant experience, capabilities and requirements.
