# Recruitment OS Community

### Building better recruitment technology together.

Recruitment OS is exploring how AI can improve recruitment beyond keyword matching, rigid filters and disconnected tools.

This repository is the public community and experimentation layer around Recruitment OS. It is a place for developers, AI engineers, recruiters, HR-tech professionals, researchers, data professionals and builders to collaborate on real recruitment challenges using synthetic data and clearly defined test cases.

## 🚀 Current Challenge

### Recruitment OS — AI Matching Challenge

Can we build an AI matching engine that understands candidates beyond keywords?

Given a job and a candidate, determine how strong the real match is — including cases where experience can compensate for a missing requirement, and cases where matching keywords hide a critical professional gap.

[Explore the AI Matching Challenge](challenges/ai-matching/)

## Who can participate?

Everyone. Participants may use Large Language Models, semantic search, embeddings, rules engines, machine learning, knowledge graphs, hybrid architectures or other approaches. There is no required AI model or technology stack.

## 🔐 Privacy by Design

All challenge data is synthetic. No real candidate CVs, personal information, client data or private Recruitment OS algorithms are included.

## 🤝 Join the Community

Build a solution. Improve a test case. Challenge an assumption. Suggest a better architecture. Open an issue. Submit a pull request. A participant does not need to build an entire system to contribute.

**Real recruitment problems. Open experimentation. Better solutions.**
